MX BIKES MOD GUIDE

Everything you need to start installing custom bikes, tracks, gear, helmets, bike graphics and tyres in MX Bikes.

01
START HERE

Finding Your Mods Folder

MX Bikes stores your normal community mods inside your Windows Documents folder. This is different from the Steam installation directory.

DEFAULT MOD DIRECTORY Documents\PiBoSo\MX Bikes\mods
1

Open File Explorer

Open Windows File Explorer and select Documents.

2

Open PiBoSo

Open the PiBoSo folder, followed by MX Bikes.

3

Open Mods

Inside MX Bikes, open the mods folder. 

Documents
└── PiBoSo
    └── MX Bikes
        └── mods
            ├── bikes
            ├── tracks
            ├── tyres
            └── rider
CAN'T FIND THE PIBOSO FOLDER?

Launch MX Bikes at least once. The game normally creates its Documents folders after it has been run.

02
BIKE MODS

Installing Modded Bikes

Custom bike packs such as OEM-style bike packs belong inside the MX Bikes bikes mod directory.

BIKE DIRECTORY Documents\PiBoSo\MX Bikes\mods\bikes
1

Download the Bike Pack

Download the bike mod from a trusted MX Bikes mod creator or community source.

2

Extract the Download

If the download is a ZIP, RAR or 7Z archive, extract it using Windows, 7-Zip or WinRAR.

3

Read the Included Instructions

Large bike packs may contain several required folders or dependencies. Always check the mod creator's installation instructions.

4

Install the Bike Files

Place the supplied bike folders and/or PKZ files into your mods\bikes directory. 

mods
└── bikes
    ├── [Bike Mod Folder]
    ├── [Bike Mod Folder]
    └── [Bike Mod].pkz
IMPORTANT — BIKE DEPENDENCIES

Some bike packs require matching tyre files or other dependencies. Install everything included or required by the pack. Missing dependencies can prevent bikes from appearing or cause problems when loading.

03
CUSTOM TRACKS

Installing Tracks

Custom tracks are one of the easiest MX Bikes mods to install. MX Bikes supports track PKZ files as well as unpacked track folders.

TRACK DIRECTORY Documents\PiBoSo\MX Bikes\mods\tracks
1

Download the Track

Download the track and check whether the creator included any additional installation instructions.

2

Extract the Archive

ZIP, RAR and 7Z downloads generally need to be extracted first.

3

Move the Track

Place the supplied track PKZ or track folder into mods\tracks.

4

Launch MX Bikes

Start MX Bikes and look for the track in the appropriate track category. 

mods
└── tracks
    ├── motocross
    │   └── [Track]
    ├── supercross
    │   └── [Track]
    └── [Track].pkz
TIP

Track category folders mainly help organize your library. Follow the track creator's folder structure when one is already included in the download.

04
RIDER CUSTOMIZATION

Installing Rider Gear

Rider kits normally use .pnt paint files. These paints must be installed for the rider model they were created for.

COMMON DEFAULT RIDER PAINT DIRECTORY Documents\PiBoSo\MX Bikes\mods\rider\riders\default_mx\paints
1

Check the Rider Model

Find out which rider model the gear was designed for. A paint made for another model may not work correctly.

2

Find the .PNT File

Rider skins are commonly distributed as .pnt files.

3

Install the Paint

Put the PNT file into the paints directory belonging to the correct rider model. 

mods
└── rider
    └── riders
        └── default_mx
            ├── paints
            │   └── YourGear.pnt
            └── gloves
MODEL MATTERS

If a gear download says it requires a specific custom rider model, install that model first and use its paint directory instead of default_mx.

05
HELMETS

Installing Helmets & Helmet Paints

There is an important difference between a helmet model and a helmet paint.

A custom paint will not work unless the helmet model it was created for is installed.

HELMET DIRECTORY Documents\PiBoSo\MX Bikes\mods\rider\helmets 
helmets
└── [Helmet Model]
    ├── [model files]
    └── paints
        ├── Design01.pnt
        └── Design02.pnt
PAINT DOESN'T SHOW?

Make sure you actually have the helmet model the paint was designed for. Putting a helmet paint into a random helmet folder will not convert it to that model.

06
GRAPHICS

Installing Bike Graphics

Bike skins and graphics are installed into the paint directory belonging to the exact bike model.

GENERAL STRUCTURE mods\bikes\[Bike Model]\paints 
mods
└── bikes
    └── [Bike Model]
        └── paints
            ├── Motogrid01.pnt
            └── Motogrid02.pnt
USE THE CORRECT BIKE

Bike paints are model-specific. A graphic kit made for one bike model should be placed in that exact bike's paints folder.

07
BIKE COMPONENTS

Installing Tyre Mods

Some custom bikes depend on additional tyre packages. These are installed separately from the bikes themselves.

TYRE DIRECTORY Documents\PiBoSo\MX Bikes\mods\tyres
1

Check the Bike Requirements

Read the bike pack instructions and determine whether a matching tyre pack is required.

2

Extract the Tyre Pack

Extract the download while preserving the folder structure supplied by the creator.

3

Install

Place the supplied files into mods\tyres.

TYRES MISMATCH

If a multiplayer server reports a tyre mismatch, make sure you're using the correct version of the tyre pack required by the bikes/server. Old or mixed tyre files can cause version mismatches.

08
TROUBLESHOOTING

Mod Not Showing?

01

Wrong Folder

Make sure you're using the Documents PiBoSo mods directory, not accidentally placing normal mods somewhere inside Steam.

02

Double Folder

Check extracted downloads for an unnecessary extra folder level.

03

Missing Dependency

Bikes, paints and other mods may require another bike, rider, helmet or tyre package.

04

Wrong Paint Model

Gear, helmets and bike graphics must be installed for the model they were created for.

05

Old Mod Version

Older bikes or tyres may not match the current version required by a server or newer mod pack.

06

Restart MX Bikes

After changing mods, completely close MX Bikes and launch it again before troubleshooting further.
